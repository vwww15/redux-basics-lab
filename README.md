
# Redux Basics Lab

## Тема
Основи Redux: принципи роботи та ключові поняття
(store, action, reducer).

## Мета роботи
Навчитися створювати Redux Store, reducer та actions,
підключати Redux до React через Provider
і використовувати useSelector та useDispatch.

## Технології
- React
- JavaScript
- Vite
- Redux
- React-Redux

## Виконані завдання
1. Встановлено Redux та React-Redux.
2. Створено itemReducer.
3. Реалізовано action creator addItem.
4. Створено Redux Store.
5. Підключено Provider до React.
6. Створено компонент ItemList для додавання елементів.
7. Додано можливість видалення елементів через REMOVE_ITEM.

## Запуск проєкту

    npm install
    npm run dev

## Результат
Реалізовано додавання та видалення елементів списку.
Роботу Redux перевірено у браузері.
Збірка npm run build завершилася успішно.
